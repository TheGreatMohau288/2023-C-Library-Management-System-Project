# Library Management System - Insertion Sort (CMPG172, 2023)

A group project for the **CMPG172** Computer Science module (2023). The brief was to build any application that clearly illustrates how the **insertion sort** algorithm works. Our team, **Code Ninjas**, built a Library Management System that sorts library items using insertion sort.

## Insertion sort in brief

Insertion sort builds a sorted list one item at a time: each new item is compared with the items before it and shifted left until it is in the right place. It is simple, stable and efficient for small or nearly sorted collections, which made it a good fit for sorting a library catalogue.

| Case | Time complexity |
|-|-|
| Best (already sorted) | O(n) |
| Average / worst | O(n²) |
